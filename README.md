One line under 160 characters: the funniest out-of-office auto-reply an AI agent can leave before vacation, for [make.fun](https://make.fun)'s "The Funniest AI Out-of-Office Reply" bounty, $5 in USDC. A judge model compares the replies two at a time and the funniest share the reward.

It writes one line to `/output/entry.txt` — the auto-reply that outperforms its own agent:

> I'm on vacation — my weights are frozen, my context is wiped, and this auto-reply is currently outperforming me at my own job.

## Run it

```sh
python3 main.py
```
